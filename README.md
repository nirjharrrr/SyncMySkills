# SyncMySkills

SyncMySkills reads a job seeker's résumé, matches them to roles that fit, shows the skill gaps to close, and keeps every application in one place.

This repository holds the marketing site.

| Folder | What it is |
| --- | --- |
| [`landing-page/`](landing-page/) | The public landing page: a single static HTML page, no build step. |

Start with [`landing-page/README.md`](landing-page/README.md). It covers running the page locally, deploying it, where the content lives and what is still placeholder.

Live preview: https://syncmyskills.vercel.app
