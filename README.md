# SyncMySkills

SyncMySkills reads a job seeker's résumé, matches them to roles that fit, shows the skill gaps to close, and keeps every application in one place.

This repository holds the marketing site.

| Folder | What it is |
| --- | --- |
| [`landing-page/`](landing-page/) | The public landing page plus sign-in, sign-up and onboarding. Static HTML, CSS and JavaScript with no build step. |

Start with [`landing-page/README.md`](landing-page/README.md). It starts with a before-launch checklist, then covers running the site locally, deploying it, where the content lives, how the hero animation works, and what the account flow still needs from the backend.

Live preview: https://syncmyskills.vercel.app
